# Better ScheduleBuilder

A UC Davis course planning tool concept designed to make schedule building easier, cleaner, and more student-centered.

This project explores how course data, scheduling constraints, and user preferences can be combined into a better planning experience than manually comparing sections one by one.

## Project overview

Course registration is stressful because students need to balance:

- Required courses
- Professor preferences
- Time conflicts
- Discussion/lab sections
- Workload balance
- GE and major requirements
- Pass time constraints

Better ScheduleBuilder is designed to help students reason through those constraints more efficiently.
